# Skills and agents for Freelance Time Tracker

There is no BMAD here, so the built-in skills win each job.

| Job | Winner | Not these |
|---|---|---|
| Scaffold planning docs | `scaffold-project` | — |
| Change the page / publish | Artifact tool (direct edit) | `design-html`, `design-shotgun` |
| Simplify existing code | `/simplify` | `health`, `review` |
| Review a diff | `/code-review` | `review`, `plan-*-review` |
| Debug a failure | `investigate` | `qa` |

## Delegating to a subagent
Suggest one; do not auto-delegate. A single-file repo rarely needs one.

## Not in scope here
The social media, LinkedIn, iOS, nonprofit and gstack deploy suites are installed but play no part in this project.
